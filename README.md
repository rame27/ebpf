# eBPF Security Suite

High-performance Linux security visibility, detection, and prevention tools
built with **libbpf + C** (CO-RE, BTF-portable). All tools emit structured
**JSON to stdout** for easy ingestion into SIEMs, log aggregators, or
command-line processing with `jq`.

---

## Features

| Feature | Binary | BPF Program | Hook type | What it detects |
|---|---|---|---|---|
| Network Traffic Monitor | `net_traffic` | `net_traffic.bpf.o` | TC ingress/egress | Per-packet IP/port/proto/direction |
| Process Execution Tracer | `proc_exec` | `proc_exec.bpf.o` | tracepoint execve | Every exec with args & parent PID |
| File Integrity Monitor | `file_integrity` | `file_integrity.bpf.o` | tp + kprobe vfs | open/write/unlink/rename/chmod on watched paths |
| Syscall Anomaly Detector | `syscall_anomaly` | `syscall_anomaly.bpf.o` | raw_tracepoint sys_enter | Burst/anomaly scoring per-pid/syscall |
| DNS Query Monitor | `dns_monitor` | `dns_monitor.bpf.o` | kprobe udp_sendmsg | DNS QNAME + QTYPE per process |
| Privilege Escalation Detector | `priv_esc` | `priv_esc.bpf.o` | kprobe commit_creds + tp | UID/GID/capability escalation |
| TCP Connection Tracker | `tcp_tracker` | `tcp_tracker.bpf.o` | kprobe tcp_connect/close | Connect, accept, close, retransmit + duration |

## Prerequisites

### Kernel requirements
- Linux **5.8+** (ring buffer, CO-RE)
- Kernel compiled with `CONFIG_DEBUG_INFO_BTF=y` (most distros: ✓)
- `CONFIG_BPF_SYSCALL=y`
- `CONFIG_KPROBE_EVENTS=y`
- `CONFIG_TRACEPOINTS=y`

Check BTF support:
```bash
ls /sys/kernel/btf/vmlinux   # must exist
```

### Build dependencies

**Ubuntu / Debian:**
```bash
sudo apt-get install -y \
    clang llvm libelf-dev zlib1g-dev \
    libbpf-dev linux-headers-$(uname -r) \
    bpftool gcc make
```

**Fedora / RHEL:**
```bash
sudo dnf install -y \
    clang llvm elfutils-libelf-devel zlib-devel \
    libbpf-devel kernel-headers bpftool gcc make
```

**Arch Linux:**
```bash
sudo pacman -S clang llvm libelf zlib libbpf linux-headers bpftool base-devel
```

## Build

### 1. Generate vmlinux.h (one-time per kernel version)

```bash
# Must be run on the target machine with BTF enabled
bpftool btf dump file /sys/kernel/btf/vmlinux format c > vmlinux.h
```

Or use the Makefile target:
```bash
make vmlinux
```

### 2. Build all features

```bash
make all
```

### 3. Build a single feature

```bash
make net_traffic        # builds obj/net_traffic.bpf.o  +  bin/net_traffic
make proc_exec
make file_integrity
make syscall_anomaly
make dns_monitor
make priv_esc
make tcp_tracker
```

### 4. Clean

```bash
make clean
```

## Running

All binaries require **root** (or `CAP_BPF + CAP_PERFMON`).

### Network Traffic Monitor

```bash
# Monitor interface eth0 (or lo, ens3, etc.)
sudo ./bin/net_traffic eth0

# Monitor loopback
sudo ./bin/net_traffic lo

# Pipe to jq for pretty-print
sudo ./bin/net_traffic eth0 | jq .
```

**Example output:**
```json
{"event":"net_traffic","ts_ns":1712345678901234,"pid":1234,"tgid":1234,"uid":1000,"comm":"curl","direction":"egress","proto":"TCP","src":"192.168.1.10","sport":54321,"dst":"93.184.216.34","dport":80,"pkt_len":74}
```

## Composing All Features

Run all monitors simultaneously and aggregate output:

```bash
IFACE=eth0

sudo ./bin/net_traffic      $IFACE  > /tmp/net.json &
sudo ./bin/proc_exec               > /tmp/exec.json &
sudo ./bin/file_integrity   /etc /var/log > /tmp/file.json &
sudo ./bin/syscall_anomaly         > /tmp/syscall.json &
sudo ./bin/dns_monitor             > /tmp/dns.json &
sudo ./bin/priv_esc                > /tmp/priv.json &
sudo ./bin/tcp_tracker             > /tmp/tcp.json &

# Tail all JSON streams:
tail -f /tmp/*.json | jq --unbuffered -c '
  {event: .event, pid: .pid, comm: .comm, ts: .ts_ns}
'
```

Pipe to a SIEM (e.g., Elastic/Splunk via Filebeat/Fluentd) by pointing those
tools at the log files, or use a named pipe:

```bash
mkfifo /tmp/ebpf_events
sudo ./bin/proc_exec > /tmp/ebpf_events &
nc -l 9000 < /tmp/ebpf_events   # stream over network
```

## Troubleshooting

| Problem | Fix |
|---|---|
| `vmlinux.h` not found | Run `make vmlinux` first |
| `bpf_object__load: Operation not permitted` | Run with `sudo` |
| `Failed to attach TC ingress` | Check interface name: `ip link` |
| `BTF not supported` | Upgrade kernel to 5.8+ with `CONFIG_DEBUG_INFO_BTF=y` |
| `libbpf.h not found` | `apt install libbpf-dev` |
| High event volume | Add PID/comm filters in userspace (post-ring-buffer) |
| BPF verifier error | Check kernel version; some features need 5.15+ |
